Kỹ năng: Writing Task 2 — đa dạng cấu trúc câu (Grammatical Range) mà không gượng

Ngữ pháp: Đảo ngữ: Never / Rarely / Seldom, Not only … but also, Only when / Only by

8 bài. Máy chấm không phân biệt hoa thường và dạng viết tắt (don't = do not), nhưng chấm chặt chính tả.

Bài 1 · Biến đổi câu

Viết lại câu bằng đảo ngữ, bắt đầu bằng từ cho sẵn.

  1. 1. People rarely read the small print. → Rarely
  2. 2. I have never seen such high prices. → Never
  3. 3. Online shopping saves time. It also encourages impulse buying. → Not only
  4. 4. People save more only when prices rise. → Only when
  5. 5. We can reduce waste only by buying less. → Only by

Bài 2 · Trắc nghiệm

Chọn đáp án đúng.

  1. 1. Seldom ___ about the environmental cost of cheap clothes.

  2. 2. Never before ___ so easy to borrow money.

  3. 3. Not only ___ prices, but it also reduces wages.

  4. 4. Only when the recession ended ___ to spend again.

  5. 5. Which sentence is NOT correct?
